# Security and Sensitive Data

This repository is public and is not an approved location for secrets, credentials, private customer records, or confidential business documents.

If sensitive material is accidentally committed:

1. stop further sharing of the affected material
2. rotate or revoke exposed credentials immediately when applicable
3. remove the sensitive data from the repository and, when necessary, from Git history
4. review related systems for unintended exposure
5. document only a sanitized summary of the incident in this public repository

For routine privacy guidance, see `docs/PRIVACY.md`.
